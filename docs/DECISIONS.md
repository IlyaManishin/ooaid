# DECISIONS: журнал решений

Что здесь:
- решения по противоречиям и пробелам в `trackfit.md`/`UI.drawio`, принятые при подготовке ТЗ;
- решения, которые агент добавляет по ходу работы (тип A из `AGENTS.md` §6).

Статусы: **ПРИНЯТО** — решение окончательное в рамках ТЗ; **ЗАМЕНЕНО** — исторический выбор, действующее решение указано в записи; **ПОДТВЕРДИТЬ** — разумное решение по умолчанию, владелец должен подтвердить или заменить (агент реализует по умолчанию и изолирует так, чтобы замена была дешёвой).

Формат новых записей агента: `D-NN | вопрос | варианты | выбор | цена отката | статус`.

## B. Пробелы в правилах (структурные)

| ID | Вопрос | Решение по умолчанию | Откат | Статус |
|---|---|---|---|---|
| D-05 | Можно ли стартовать вручную день с заданным автостартом, не дожидаясь времени | Да (в макете 1А кнопка «Начать тренировку» стоит рядом с «Автостарт 18:30»). Автостарт при уже идущей/закрытой сессии ничего не делает. | малый | ПОДТВЕРДИТЬ |
| D-06 | Запуск программы в 20:00 с первым днём «автостарт 18:30» | Автостарт для первого слота включён, только если время ещё не наступило (`autoStartEnabled`). Иначе сессия сразу «Пропущена» — это бессмысленно. | малый | ПОДТВЕРДИТЬ |
| D-07 | Дедлайн выходит за полночь (старт 23:30 + 90 мин) | `deadlineAt = min(start + длительность, 00:00 следующих суток)`; причина закрытия `MIDNIGHT`. Следует из «автоматически в 00:00». | малый | ПРИНЯТО |
| D-08 | Когда цикл считается пройденным; с чего начинается следующий | Цикл закрыт, когда закрыт последний слот (рабочий — закрыт; отдыха — наступила следующая дата). Новый цикл — с **того же стартового индекса** (полный оборот возвращает к стартовому дню), с даты решения + 1 сутки, `cycleNumber + 1`. | средний | ПОДТВЕРДИТЬ |
| D-09 | Что, если пользователь не отвечает на вопрос о смене программы (итог цикла) | Календарь цикла «замораживается» (`AwaitingDecision`), модалка итогов цикла не закрывается без выбора и появляется при каждом запуске, пока решение не принято. Дни между окончанием цикла и решением ни к какому циклу не относятся. | средний | ПОДТВЕРДИТЬ |
| D-10 | Что показывать на HOME между решением «новый цикл» и началом нового цикла (сегодня уже «ничья» дата) | Минимум: календарь нового цикла (все дни заблокированы) + карточка-заглушка со строкой `home_cycle_pause` (плейсхолдер). Новых экранов не делать. | малый | ПОДТВЕРДИТЬ |
| D-11 | «Остановить» без подтверждения (так в макете и `trackfit.md`), хотя действие разрушительное | Без подтверждения. Рекомендация владельцу: добавить диалог (дёшево, в `:app`). | малый | ПОДТВЕРДИТЬ |
| D-12 | Что «очищается» при остановке/смене программы и что такое «история тренировок» | Очищается **прогресс текущего запуска**. Лог тренировок (`WorkoutLogEntry`) и личные рекорды **не** очищаются. Экран «Прогресс» — заглушка; лог копится. | средний | ПОДТВЕРДИТЬ |
| D-13 | Несколько неотмеченных отчётов после долгого отсутствия | Показ по очереди от старых к новым, после загрузки HOME. Политика — `ReportPresentationPolicy` (заменяема, напр. «только последний»). | малый | ПОДТВЕРДИТЬ |
| D-25 | Перевод часов назад / смена пояса | Reconcile монотонен: `lastReconciledAt` не уменьшается, закрытое не «открывается». Даты слотов фиксированы; автостарт вычисляется в текущем поясе. | — | ПРИНЯТО |
| D-24 | Можно ли менять тип существующего упражнения | Нет (параметры разных типов несовместимы). Меняется тип только пересозданием. | малый | ПРИНЯТО |
| D-30 | `applicationId` | `app.trackfit` (если владелец не сообщит иное). | — | ПОДТВЕРДИТЬ |
