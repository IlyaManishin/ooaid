# Задача агенту — перенести начатый M0 TrackFit на Java

Доведи существующий каркас Android-приложения до критериев M0 из [ТЗ](TZ.md). Объём задачи заканчивается на четырёх вкладках с экранами-заглушками. Бизнес-функции начинаются со следующих этапов.

## Перед правками

Прочитай [AGENTS.md](../AGENTS.md), [ТЗ](TZ.md) целиком, [архитектуру](ARCHITECTURE.md), [решения](DECISIONS.md), [инструкцию по сборке](SETUP.md), [правила TrackFit](trackfit.md) и [карту экранов](UI_MAP.md). Сверь вкладки с [макетом](ui/UI.drawio). Затем посмотри текущую ветку, `git status`, изменения и новые файлы. На момент постановки задачи в `feat/m0-bootstrap` часть M0 лежит в неотслеживаемых файлах. Сохрани уже сделанное, включая правки в карте экранов, журнале решений и `.gitignore`.

## Работа

1. Перенеси сборку с `settings.gradle.kts` и корневого и модульных `build.gradle.kts` на Gradle Groovy DSL. Сохрани version catalog, три модуля и связи `:app → :infra → :domain` и `:app → :domain`. Для `:domain` используй Java Library и JDK 17, для Hilt — Java `annotationProcessor`. Убери прямые плагины и зависимости прежней реализации (Kotlin JVM, Compose, KSP, kotlinx.serialization). Проверь Gradle Wrapper и добавь недостающие файлы согласно SETUP.
2. Перенеси `TrackFitApplication.kt` и `MainActivity.kt` в Java. Замени `MainScaffold.kt` и `TrackFitTheme.kt` эквивалентом на Android Views с XML-разметкой, светлой темой Material и навигацией через Fragment. Сохрани `applicationId`, запуск из манифеста, портретную ориентацию, обработку системных отступов и существующие русские строки в ресурсах.
3. Сделай «Главную» стартовой. Порядок нижних вкладок — «Главная», «Прогресс», «Тренер», «Профиль». Сохрани отдельный стек каждой вкладки, восстановление при возврате и поведение повторного нажатия на выбранную вкладку. После переноса удали заменённые Kotlin-исходники. Код приложения и тестов во всех трёх модулях пиши на Java.
4. Перенеси `checkArchitecture` в новую сборку. В текущем каркасе проверка строк с кириллицей выполняется только для `.kt`. По §15 архитектуры проверь литералы в Java, ссылки на строковые ресурсы в XML-разметке и меню, а также появление `.kt` в исходниках и тестах любого модуля. Сохрани проверки границ модулей и доступа к часам.

## Приёмка

- Из корня проекта выполни `./gradlew checkArchitecture :domain:test :infra:testDebugUnitTest :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`. В отчёте укажи результат, включая задачи без тестовых исходников.
- На доступном эмуляторе или устройстве запусти приложение с иконки. Проверь стартовую вкладку, обход всех четырёх вкладок, повторный выбор активной вкладки и системную кнопку «Назад». Если устройства нет, укажи это в отчёте.
- Обнови документы по процедуре M0. Перечисли, какие части каркаса перенесены, где собран APK и какие проверки удалось выполнить. При блокере сборки приложи команду и фактическую ошибку.
