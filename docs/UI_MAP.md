# UI_MAP: текстовая карта макета

Источник: `docs/UI.drawio` (3 листа), точный дамп — `docs/ui-dump/UI.dump.txt`. Макет **неполный** и будет обновлён (процесс — `AGENTS.md` §9). При обновлении макета этот файл обновляется в том же коммите.

Обозначения макета (1А, 2В, 3Б…) — справочные, в макете есть дубли (D-29); здесь — канонические имена. Тексты в `strings.xml` брать из макета дословно, где они есть.

Общее: портретная ориентация; нижняя панель из 4 вкладок — 🏠 Главная · 📊 Прогресс · 👤 Тренер · ⚙️ Профиль — видна на всех полноэкранных экранах (в т. ч. в конструкторе и на экране тренировки).

## 3. Граф навигации (сводка)

```
HOME ─► PROGRAMS ─► [START_DAY_PICKER] ─► HOME
              │└──► PROGRAM_EDITOR ─► DAY_EDITOR ─► [EXERCISE_TYPE_PICKER] ─► [EXERCISE_EDITOR_*]
HOME ─► WORKOUT ─► (HOME + [DAY_REPORT | CYCLE_REPORT])
CYCLE_REPORT ─(сменить)─► PROGRAMS ;  ─(новый цикл)─► HOME
COACH_LIST ─► COACH_CARD
PROFILE ─► SETTINGS | PROFILE_EDITOR | RECORDS ─► RECORD_VIEW ─► [RECORD_EDITOR]
```

## 4. Тексты

Статусы дня: «Не начато», «Выполняется», «Завершено», «Не завершено», «Пропущено». Итоги цикла: «Полный успех», «Частичный успех», «Полный провал». Типы (теги): Strength, Cardio, Balance, Stretch. Push автостарта: «Ты опаздываешь? Я подожду!».

## 5. Типы упражнений (из макета, лист 2)

| Тип | Обязательные | Опциональные | В списке упражнений (DAY_EDITOR) |
|---|---|---|---|
| Сила (`Strength`) | название, подходы, повторения | вес, отдых между подходами, заметка | название; подходы × повторения; вес (если указан) |
| Кардио (`Cardio`) | название, продолжительность | темп/интенсивность, целевой пульс, заметка | название; продолжительность; темп/интенсивность (если указаны) |
| Баланс (`Balance`) | название, продолжительность | подходы, сторона выполнения, заметка | название; продолжительность; подходы (если указаны) |
| Гибкость (`Stretch`) | название, продолжительность | подходы, сторона выполнения, заметка | название; продолжительность; подходы (если указаны) |

Общее правило: заметки не отображаются в списке упражнений; все обязательные поля заполнены до сохранения. Сторона выполнения — левая / правая / обе (пояснение в макете: «для какой стороны тела выполняется упражнение… например, подъём ноги в сторону отдельно для каждой ноги или боковая планка»).
