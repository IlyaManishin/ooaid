# M0 · Каркас TrackFit на Java

## Изменения

- Gradle Wrapper, Groovy DSL и каталог версий для `:domain` (Java Library), `:infra` и `:app`. Hilt использует Java `annotationProcessor`.
- Java Activity и Fragment, View Binding, светлая тема Material 3 и системные отступы. Стартовая вкладка «Главная», у каждой из четырёх вкладок свой стек. Повторный выбор активной вкладки оставляет текущий экран.
- `checkArchitecture` проверяет границы модулей, чтение часов в домене, Java-литералы, ссылки на строки в XML и наличие Kotlin-файлов в основных и тестовых исходниках.
- D-35 фиксирует версии и выбор NavigationUI. Вместе с платформой 37.2 используется Build Tools 36.0.0 из таблицы совместимости AGP. В пакете 37.0.0 отсутствует AAPT, который требует AGP 9.5.1.

## Проверки

```bash
./gradlew checkArchitecture :domain:test :infra:testDebugUnitTest :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Гейт завершился с `BUILD SUCCESSFUL`. Все три тестовые задачи получили `NO-SOURCE`. Lint завершился без ошибок, с предупреждениями об ориентации, настройке резервного копирования и значке приложения. Отрицательные проверки `checkArchitecture` отклонили подставленные нарушения.

APK расположен в `app/build/outputs/apk/debug/app-debug.apk`. Проверены подпись APK, идентификатор `app.trackfit` и наличие `MainActivity` в качестве точки запуска.

Ручная проверка не выполнена. ADB не обнаружил эмулятор или устройство.

## Ручная приёмка

1. Установить debug APK и открыть TrackFit с иконки. Должна открыться «Главная».
2. Переключить «Прогресс», «Тренер», «Профиль» и вернуться на «Главную». Заголовок и выбранная вкладка должны совпадать.
3. Повторно нажать выбранную вкладку. Текущий экран должен сохраниться.
4. На «Профиле» нажать системную кнопку «Назад». Приложение вернётся на «Главную». Повторное нажатие выведет из приложения.
