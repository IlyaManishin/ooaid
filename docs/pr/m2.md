# M2 · Движок тренировок

Движок привязывает дни к календарю, догоняет автостарты и дедлайны, фиксирует упражнения и закрывает день или цикл. D-39 фиксирует воспроизводимые идентификаторы и поведение при откате часов.

Полный гейт из AGENTS.md прошёл. Юнит-тесты проверяют ручной старт, автостарт в фоне, пропуски, полночь, долгую паузу, итоги, часовые пояса, DST и повторный успех. Тестовые задачи Android-модулей получили `NO-SOURCE`.

Ручная проверка не выполнена, поскольку ADB не обнаружил эмулятор или устройство. Сквозной сценарий через UI предусмотрен в M4.
