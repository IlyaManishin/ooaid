# M3 · Контроллеры и хранилище

Каталог, прогресс, отчёты и лог сохраняются Room. Прогресс сериализуется в версионированный JSON. Контроллеры выполняют команды на одном Executor и публикуют состояние после записи. Начальная схема Room экспортирована в репозиторий. Изменения зависимостей описаны в D-40.

Гейт из AGENTS.md прошёл. Robolectric проверил четыре типа упражнений, восстановление состояния после повторного открытия базы и откат команды при ошибке записи лога.

Для проверки демоданных собрать debug APK с `-Ptrackfit.seedExamples=true` и запустить на пустой базе. Ручная проверка не выполнена из-за отсутствия устройства или эмулятора.
