# M4 · Программы и тренировки

Доступны конструктор, формы четырёх типов упражнений, запуск с выбранного дня, календарь, тренировка и очередь итогов. D-41 уточняет отмену правок рабочего дня.

Полный гейт прошёл. Тесты ViewModel прошли сценарии создания, запуска и завершения тренировки, принятия итога, начала нового цикла и отмены правок.

Ручная проверка не выполнена из-за отсутствия устройства или эмулятора. Для неё создать программу с рабочим днём и упражнением, запустить программу, отметить упражнение, завершить тренировку и выбрать следующий цикл.
