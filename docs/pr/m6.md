# M6 · Виртуальный тренер

Добавлены каталог тренеров, виджет на главной и реплики во время показа итогов. Тренер выбирается из локальных assets, память хранится в Room. Биографии, изображения и реплики временные по D-17.

Полный гейт прошёл. Тесты проверили реплики для отчётов, контекст повторного успеха, десятиминутную паузу, приоритеты и подключение новых правил. Ручная проверка не выполнена, устройство или эмулятор недоступны.
