# M7 · Профиль, рекорды и настройки

Профиль сохраняет дату рождения и копию выбранного фото в приватном хранилище. Рекорды поддерживают свободные параметры, редактирование и удаление. D-43 уточняет заполнение параметров. Переключение push пересчитывает расписание уведомлений. Вкладка «Прогресс» остаётся заглушкой по F-74.

Полный гейт прошёл. Проверены дата рекорда, возраст и переход с обеих предыдущих схем Room без потери данных. Для ручной проверки открыть профиль, выбрать фото, добавить и отредактировать рекорд, переключить push. Устройство или эмулятор недоступны.
